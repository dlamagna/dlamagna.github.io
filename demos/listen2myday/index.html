Listen2MyDay: a journal with the day around it

A journal app that adds the day's music, weather, health and listening stats, plus any open data you choose, to each entry. It is for a small group of invited people: everyone has a private journal and can share journals with others.

In progress, private repository: this page explains how it works.

An entry

How it works

  1. Write

    On a phone, where it installs like an app, or on a computer, in a simple rich-text editor.

  2. Sign in

    Only invited people can get in. Each has a private journal and can keep shared journals with others.

  3. Save

    Entries and photos are stored on Cloudflare, so the app costs nothing to run for a small group.

  4. Add the day

    Each source of context, such as weather or music, plugs in the same way, so new ones can be added one at a time.

Engineering

Tests

Automated tests run the backend exactly as it runs on Cloudflare, and browser tests click through the app like a user. Privacy tests use made-up data only.

Limits built in

Every build checks that the app stays small and within Cloudflare's free plan, and that every written requirement has a test.
